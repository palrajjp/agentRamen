# GitGraph for VS Code

Thin wrapper over the `gitgraph` CLI. Requires `gitgraph` installed and on PATH (or set `gitgraph.executable`).

Commands (Command Palette): Index Repository, Find Context for Task, Show Impact of Current File, Show History of Current File. Results appear in the "GitGraph" output channel.

Run in development: open this folder in VS Code and press F5. Package with `npx @vscode/vsce package`.
