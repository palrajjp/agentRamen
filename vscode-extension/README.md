# agentRamen for VS Code

Thin wrapper over the `agentramen` CLI. Requires `agentramen` installed and on PATH (or set `agentramen.executable`).

Commands (Command Palette): Index Repository, Find Context for Task, Show Impact of Current File, Show History of Current File. Results appear in the "agentRamen" output channel.

Run in development: open this folder in VS Code and press F5. Package with `npx @vscode/vsce package`.
